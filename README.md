# Diagnostic Innovation Hub

Static website package for GitHub Pages, exported from the reviewed Illinois VetMed concept on 5 November 2026.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository named diagnostic-innovation-hub.
2. Extract this ZIP. Upload index.html, styles.css, app.js and .nojekyll to the root of the repository. Upload the extracted files, rather than the ZIP or its enclosing folder. Include README.md if desired. The three visible website files are sufficient if your upload interface hides .nojekyll.
3. Commit the files to the main branch.
4. Open repository Settings, then Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Choose main and /(root), then Save.
7. After publication, use Visit site in Pages settings to obtain the actual public address. Publication can take up to 10 minutes.

The address normally follows the pattern https://YOUR-USERNAME.github.io/diagnostic-innovation-hub/ with your real GitHub username substituted. This is an address pattern, not a deployed website.

No build, package installation or server code is required. Asset links are relative so the website works in a GitHub Pages repository subpath. Pages visitors do not need a ChatGPT account.

## Google Sites alternative

Google Sites is suitable if collaborators need a visual page editor. Either rebuild the content with native Google Sites sections, or embed the externally hosted Hub. To embed a hosted website, use Insert then Embed, enter the public website address and insert it. A full-page embed can also be added from Pages. An embed keeps the externally hosted site as its source, so edits to that design remain code edits rather than native Google Sites edits.

## Current scope

This is a public-review concept with five proposed service areas. The banner and availability notes remain visible. Product inventory, prices, service ownership and contact information have not been confirmed. The project brief builder creates text locally and does not send an inquiry, place an order or save visitor information. The case-study pathway is illustrative. The institutional masthead is a prototype representation and should be replaced with approved components for the final VetMed site.

## Hosting fit

GitHub Pages is appropriate for an informational review prototype. GitHub does not allow Pages to host sites primarily directed at commercial transactions or online businesses. Use the institutional VetMed platform or another suitable host for a future antibody storefront and commercial service ordering.

Official limits are documented at https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## Later integration

The site can be adapted into the existing VetMed CMS. Reuse approved institutional navigation and scope the CSS to the Hub section. The hosting choice does not by itself plug the site into VetMed or create a vetmed.illinois.edu address.
